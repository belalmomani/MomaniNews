# متجري (تطبيقات GitHub داخل التطبيق)

القائمة الجانبية ← «متجري»: تطبيقاتك المعتمدة بأيقونتها ولقطاتها ووصفها وتصنيفها، مع «تنزيل مباشر».

## أين يوضع شرح التطبيق؟ (مكان واحد، بأي طريقة)
داخل **مستودع التطبيق على GitHub**، في مجلد `store/` (على الفرع الرئيسي). المتجر يسحب منه مباشرة:

| الملف | المحتوى |
|---|---|
| `store/app.json` | الشرح: `{"title": "...", "description": "...", "category": "news"}` (كل حقل اختياري؛ التصنيف: apps / games / tools / news / other؛ الوصف حتى 2000 حرف) |
| `store/icon.png` | الأيقونة (مربعة) |
| `store/screenshot1.png` ... `screenshot8.png` | لقطات الشاشة |

أي طريقة تكتب هذه الملفات تصلح: تعديل يدوي على موقع GitHub، أو أداة برمجية (سكربت أو GitHub Action)، أو ذكاء اصطناعي تطلب منه أن يكتب `store/app.json` ويرفعه (أعطه المثال أعلاه). لا حاجة لأي اتصال بالتطبيق أو بـ Supabase.

ثم في لوحة الإدارة ← «متجري» ← التطبيق ← **«سحب كل شيء من GitHub»** (يستبدل الاسم والوصف والتصنيف) أو **«تحديث الإصدار والصور»** (يُبقي نصوصك التي عدّلتها يدوياً). الصور تُسحب في الحالتين.

أولوية الوصف: `store/app.json` ← خانة About للمستودع ← أول فقرة من README.

مثال `store/app.json`:
```json
{
  "title": "اسم التطبيق",
  "description": "شرح قصير للتطبيق وما يفعله.",
  "category": "tools"
}
```

## لإضافة تطبيق (من لوحة الإدارة ← «متجري (تطبيقات GitHub)»)
1. في مستودع التطبيق على GitHub:
   - انشر Release فيه ملف `.apk` (الأول في الإصدار يُستعمل).
   - أضف مجلد `store/` فيه: `icon.png` (أيقونة مربعة) و`screenshot1.png` ... `screenshot8.png` (لقطات، حتى 8). الأسماء بحروف صغيرة؛ الصيغ png/jpg/webp.
   - ضع وصفاً في About للمستودع (يُسحب كوصف مبدئي، وتعدّله لاحقاً).
2. في التطبيق: «＋ إضافة تطبيق من GitHub» ثم اكتب `owner/name` أو رابط المستودع. يدخل **معلّقاً** (لا يراه أحد).
3. راجعه ثم «اعتماد وتصنيف» واختر التصنيف. يمكنك تعديل الاسم والوصف، و«تحديث من GitHub» لسحب إصدار جديد أو صور جديدة (الاسم والوصف والتصنيف لا يُمسّ).

## إن لم تجهّز شيئاً
- الوصف: إن كان About فارغاً يُؤخذ أول فقرة من README.
- الأيقونة: إن لم يوجد `store/icon.png` تظهر صورة حساب المالك على GitHub.
- اللقطات: إن لم توجد `store/screenshot*` تُؤخذ صور README (png/jpg/webp).
- لتطبيق المومني نيوز نفسه: المجلد `store/` موجود في المشروع وفيه `icon.png`. أضف إليه لقطات من هاتفك باسم `screenshot1.png` ...
- بعد رفع التغييرات إلى المستودع اضغط «تحديث من GitHub» على التطبيق في لوحة الإدارة. الوصف يُملأ فقط إن كان فارغاً (لا يُكتب فوق وصف عدّلته).

## الأمان
- لا يظهر شيء قبل اعتماد المدير (القاعدة تفرض ذلك).
- رابط التنزيل يُقبل فقط إن كان https من `github.com/<نفس المستودع>/releases/download/…apk`.
- الصور من نطاقات GitHub فقط.
- التنزيل عبر مدير تنزيلات النظام؛ التثبيت بموافقة المستخدم من إشعار التنزيل، وأندرويد نفسه يتحقق من التوقيع. التطبيق لا يحمل إذن تثبيت في نسخة المتجر (Google Play).
- لا تعتمد إلا تطبيقات تثق بها وتملكها.

## ملاحظات
- GitHub يحدّ الطلبات المجهولة بنحو 60 في الساعة؛ كل إضافة أو تحديث يستهلك 3.
- Android أقل من 10: يُفتح رابط التنزيل في المتصفح بدل مدير التنزيلات.
