# قائمة النشر النهائية — المومني نيوز

## 0) ما فُحص قبل التسليم (في بيئة التطوير، دون بناء أندرويد)
- اختبارات الجالب: 202 ناجحة. اختبارات قاعدة البيانات المحلية: 398 فحصاً ناجحاً. اختبارات دالة `send-push`: 6 ناجحة.
- كل ملفات `.github/workflows/*.yml` (13) سليمة البنية.
- بحث عن أسرار في المستودع: لا يوجد (المطابقات الوحيدة تعليق واختبار بقيمة وهمية، و`google-services.json` معرّفات عامة بطبيعتها).
- **لم يُبنَ تطبيق أندرويد ولم تُجرَّب شاشاته هنا.** البناء الحقيقي وكل اختبارات Kotlin تجري في GitHub Actions عندك.

## 1) المستودع
1. احذف محتوى المستودع القديم (بما فيه مجلدا `src/` و`workflows/` الزائدان في الجذر، و`backend/` القديم إن وُجد).
2. ارفع محتوى `MomaniNews-FINAL.zip` (بدون المجلد الأول).
3. تأكد أن `gradle/wrapper/gradle-wrapper.jar` موجود (وإلا يولّده الـ workflow).

## 2) Supabase
1. SQL Editor ← الصق `MomaniNews-supabase-FINAL.sql` كاملاً ← Run. اقرأ التقرير: لا يجب أن يبقى أي ❌.
2. Authentication ← Providers ← Google مفعّل بالسر **الجديد** (بعد التدوير).

## 3) أسرار GitHub (Settings ← Secrets and variables)
- Secrets: `SUPABASE_URL`، `SUPABASE_SERVICE_ROLE_KEY` (**جديد بعد تدوير `sb_secret`**)، وللمتجر: `RELEASE_KEYSTORE_BASE64`، `RELEASE_KEYSTORE_PASSWORD`، `RELEASE_KEY_ALIAS`، `RELEASE_KEY_PASSWORD`.
- Variable: `PRIVACY_URL` (رابط سياسة الخصوصية بعد تفعيل GitHub Pages).
- فعّل GitHub Pages لمجلد `web` ولوحة الإدارة (workflow `deploy-admin`).

## 4) الأمان (إلزامي قبل النشر العام)
- دوّر مفتاح `sb_secret` المكشوف في Supabase، وسر Google OAuth المكشوف في Google Cloud، وحدّث الأسرار في GitHub وSupabase.
- لا تضع ملف حساب خدمة Firebase في المستودع ولا ترسله في المحادثة.

## 5) تشغيل أول مرة (Actions، بهذا الترتيب)
1. **Build Android APK** ← ثبّت على هاتف حقيقي وجرّب (القسم 7).
2. **Fetch news (RSS)** يدوياً مرة، ثم راجع الأخبار المعلّقة في لوحة الإدارة.
3. **Classify old news** (dry_run ثم فعلي).
4. **Backfill media** (dry_run ثم فعلي، ودفعات حتى `before_id`).
5. **Diagnose failing sources** وأرسل النتيجة إن لزم.
- الجالب المجدول يعمل كل 30 دقيقة، لكن GitHub قد يتأخر؛ للانتظام استعمل مشغّلاً خارجياً (cron-job.org) بعد موافقتك.

## 6) النشر
- **APK مباشر + مقارن التحديث داخل التطبيق:** workflow «Publish APK release» ينشر إصداراً `build-<code>`.
- **Google Play:** workflow «Build signed release (AAB + APK)» ثم ارفع الـ AAB. ترقيم `versionCode` موحّد في كل المسارات (دقائق منذ 1/1/2026 UTC) فيزيد دائماً. اتبع `docs/PLAY_STORE.md` (سياسة الخصوصية، أمان البيانات، حذف الحساب موجود داخل التطبيق).
- **الإشعارات الفورية (اختياري):** `docs/PUSH_FCM.md` (4 خطوات). الإشعار التلقائي عند الاعتماد: `update public.push_settings set mode='off'|'important'|'all'`.

## 7) اختبار الهاتف قبل الإعلان
- الدخول بحساب Google يظهر نافذة الحساب مباشرة.
- الرئيسية: الشريط العلوي (بحث/صور/فيديو/جرس)، الترتيب والمرشحات، القصص، شريط الأخبار والرادار، القائمة الجانبية.
- فتح خبر: الصورة/الفيديو، التفاعلات، التعليق، المتابعة، الحفظ.
- الإشعارات: مقروء/غير مقروء، تعليم الكل.
- الإعدادات ← البحث عن تحديثات: يعرض «أحدث إصدار» أو إصداراً أحدث فعلاً.
- لوحة الإدارة: اعتماد جماعي، حظر ناشر، تصنيف.

## 8) حدود معروفة
- المتابعة والحفظ والإخفاء وحالة قراءة الإشعارات محلية على الجهاز (بلا مزامنة).
- الموقع في الرادار هو المنطقة (لا إحداثيات في البيانات).
- حجم الأخبار يعتمد على المصادر: أضف مصادر محلية (بلديات ومدارس) عند توفر روابط خلاصاتها.
- خطة Supabase المجانية: 5 جيجا نقل غير مخزَّن و1 جيجا تخزين و500 ميجا قاعدة بيانات، ويتوقف المشروع بعد 7 أيام بلا نشاط.
