# لوحة الأدمن (ويب)

صفحة واحدة `admin/index.html` بلا مكتبات خارجية. تُفتح من المتصفح (الهاتف أو الحاسوب) وتدخل بحساب Google. **الدور `admin` يُفحص في القاعدة (RLS)**، فالصفحة نفسها ليست حاجز الأمان: لو فتحها غير مدير لن يقرأ ولن يكتب شيئاً.

## ما فيها حالياً
- أخبار بانتظار الاعتماد: اعتماد / رفض / أرشفة / إرجاع للانتظار (مع تأكيد).
- كل الأخبار (آخر 100).
- إضافة خبر يدوي (نشر فوراً أو حفظ للمراجعة).

- التعليقات: إخفاء / إظهار / حذف.
- طلبات التوثيق: عرض صورة الهوية (رابط مؤقت 5 دقائق)، توثيق، رفض مع سبب.
- الإعلانات: اعتماد (مع مدة بالأيام) أو رفض.
- المستخدمون: حظر / رفع حظر، منح أو إزالة صلاحية المدير (لا تستطيع تخفيض نفسك).

- الإشعارات: إرسال إشعار عام لكل المستخدمين (مع رقم خبر اختياري) وحذف الإشعارات.
- الإعلانات: بالإضافة لطلبات الاعتماد، قسم «الإعلانات المعتمدة» (تمديد / إيقاف / حذف).
- المصادر: إضافة مصدر (https) وتعطيله/تفعيله وحذفه. الكلمات المفتاحية: إضافة (لكل المناطق أو منطقة) وتعطيل/تفعيل/حذف.

القادم: تبويب لعرض الإعلانات المعتمدة وإنهائها، وإدارة المصادر والكلمات المفتاحية.

## النشر المجاني على GitHub Pages
1. في المستودع: Settings → Pages → **Source: GitHub Actions**. (على الحساب المجاني تتطلب Pages أن يكون المستودع **عاماً**؛ إن أردته خاصاً استخدم Cloudflare Pages المجاني وأخبرني.)
2. ادفع الملفات؛ يعمل workflow «Deploy admin panel» وينشر الصفحة. رابطها يظهر في Actions (غالباً `https://اسمك.github.io/اسم-المستودع/`).

## إعداد الدخول بـ Google للويب (مرة واحدة)
1. **Google Cloud → Credentials → عميل Web → Authorized redirect URIs** أضف:
   `https://jpnifyumqmkbgxcqnyqb.supabase.co/auth/v1/callback`
2. **Supabase → Authentication → URL Configuration → Redirect URLs** أضف رابط اللوحة المنشور (مع `/` في النهاية).
3. افتح اللوحة وادخل ببريد الأدمن.

## الأمان
- الصفحة تعرض النصوص كنص فقط (لا HTML)، ورابط `javascript:` لا يُعرض، وسياسة CSP تمنع الاتصال إلا بـ supabase.co.
- الجلسة في `sessionStorage` (تُمحى بإغلاق التبويب).
- المفتاح داخلها عام (publishable) بتصميمه. لا تضع `service_role` فيها.

## ما اختُبر
اختبار آلي في Chromium حقيقي (`admin/tests/panel_test.py`) مقابل خادم **وهمي** لـ Supabase: ظهور الدخول بلا جلسة، رفض غير المدير دون جلب أخبار، الاعتماد (PATCH)، إضافة خبر، رفض رابط صورة http، ومنع XSS. **لم يُختبر** الدخول الحقيقي بـ Google ولا الاتصال الفعلي بمشروعك؛ هذا يتم عندك بعد النشر.

## الإدارة داخل التطبيق
عند الدخول بحساب مدير يظهر في شاشة «الحساب» زر **لوحة الإدارة**: الأخبار (اعتماد/رفض/أرشفة/حذف)، إضافة خبر، التعليقات (إخفاء/حذف)، طلبات التوثيق (عرض المستند في المتصفح برابط موقّع 5 دقائق، قبول/رفض)، الإعلانات (اعتماد بمدة، رفض، تمديد، إيقاف، حذف)، المستخدمون (حظر، تغيير الصلاحية)، وإرسال إشعار عام. إظهار الزر للعرض فقط؛ الصلاحية الفعلية تفرضها القاعدة (RLS) في كل طلب، فغير المدير يحصل على خطأ أو قائمة فارغة حتى لو فتح الشاشة. **لم تُبنَ ولم تُجرَّب على جهاز بعد.**
