# إعداد الخادم (PHP) — هيكل المرحلة 3

## ما هو موجود الآن

هيكل بنية تحتية فقط، **بدون نقاط الأخبار** (تنتظر مراجعة مخطط قاعدة البيانات الفعلي):

- `GET /api/v1/health` — يرجع `{"status":"ok"}`.
- `GET /api/v1/health/db` — يختبر الاتصال بقاعدة البيانات فقط، ولا يقرأ جداول ولا يكشف تفاصيل.
- موجّه، وتحقق صارم من المدخلات (`Input`)، واستجابات JSON موحدة، وأخطاء عامة بلا تسريب مسارات أو قيم.

## بنية الرفع على الاستضافة

ارفع محتويات مجلد `backend/` إلى جذر الموقع (`htdocs/`) بحيث يصبح:

```
htdocs/
  api/v1/index.php
  api/v1/.htaccess
  api/v1/ping.php        (ملف اختبار مؤقت: احذفه بعد الاختبار)
  app/                   (كود الخادم؛ محمي بـ .htaccess من الوصول المباشر)
```

لا ترفع `backend/tests/`.

## ملف الإعداد (الأسرار على الخادم فقط)

1. انسخ `app/config.sample.php` إلى `app/config.php` **على الخادم**.
2. املأ بيانات قاعدة البيانات في `config.php` فقط. الملف مُستثنى من Git عبر `.gitignore`.
3. لا ترسل محتوى `config.php` أو كلمة المرور في أي محادثة أو مستودع.

## الاختبار بعد الرفع

افتح من متصفح ثم من أداة غير متصفحية (curl أو Postman):

1. `https://<نطاقك>/api/v1/health` → يجب أن يظهر `{"status":"ok"}`. إن ظهرت صفحة HTML أو JavaScript فالاستضافة تعترض الطلبات غير المتصفحية، وهذا يغيّر الخطة.
2. `https://<نطاقك>/api/v1/health/db` بعد إنشاء `config.php` → `{"db":"ok"}`. وقبل إنشائه يجب أن يرجع خطأ 500 عاماً.
3. `https://<نطاقك>/api/v1/ping.php` → معلومات الإصدار والإضافات (pdo_mysql وcurl).

إذا لم تعمل المسارات بدون `index.php` (أي `/api/v1/health` يعطي 404 من الاستضافة)، فجرّب `/api/v1/index.php/health`، وأخبرني لأعدّل الإعداد.

## ما تم اختباره وما لم يُختبر

- **اختُبر محلياً:** صياغة PHP 8.3، و40 اختباراً (الموجّه، والتحقق من المدخلات، والإعداد)، وتجربة حقيقية بخادم PHP المدمج للمسارات الأربعة أعلاه.
- **لم يُختبر:** إعادة الكتابة في `.htaccess` على Apache، والاتصال بقاعدة بيانات فعلية، وتوافق PHP 7.4 (كُتب الكود بصياغة متوافقة لكن لم يُجرَّب)، والسلوك على InfinityFree.

لتشغيل الاختبارات محلياً:

- `php backend/tests/run.php` (الموجّه والمدخلات والإعداد)
- `php backend/tests/auth_tests.php` (رموز الجلسة والتحقق من Google ID Token بمفتاح RSA مولَّد للاختبار وجالب مفاتيح وهمي؛ لا اتصال شبكي)

**ملاحظة:** كود المصادقة (`app/Auth/`) مكتوب ومختبر كوحدات، لكنه **غير موصول بأي مسار** في `index.php` بعد. مسارات `/auth/google` و`/me` والتصويت والتعليقات تنتظر مخطط قاعدة البيانات الفعلي. والتحقق الفعلي من رمز Google يحتاج اتصالاً صادراً من الاستضافة إلى `googleapis.com`، وهذا لم يُختبر على InfinityFree.
