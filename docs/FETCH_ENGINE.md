# محرك جلب الأخبار

يجلب أخباراً من مصادر RSS/Atom المفعّلة، ويطابق الكلمات المفتاحية (عبين، عبلين، صخرة، المومني) بعد تطبيع عربي، ويحفظ ما يجده **بحالة pending** فقط. لا شيء يظهر في التطبيق قبل اعتماد المشرف.

## التشغيل (مرة واحدة)
1. في Supabase → SQL Editor شغّل `supabase/migrations/20261017150000_fetch_engine.sql`.
2. في GitHub → Settings → Secrets and variables → Actions أضف سرّين:
   - `SUPABASE_URL` (مثل https://xxxx.supabase.co)
   - `SUPABASE_SERVICE_ROLE_KEY` (من Supabase → Project Settings → API). **لا تضعه في الكود أو التطبيق أبداً.**
3. أضف مصادر من لوحة الإدارة (تبويب المصادر) بنوع `rss` ورابط https للخلاصة.
4. Actions → "Fetch news (RSS)" → Run workflow للتجربة. بعدها يعمل تلقائياً كل 30 دقيقة دون أي زيارة للتطبيق.

## القواعد
- كلمة المنطقة (region/alias) تكفي للمطابقة؛ «عجلون» وحدها (context) لا تكفي.
- «صخرة» غامضة (needs_context): تحتاج كلمة سياق (عجلون، بلدية، قرية…).
- كلمات الاستبعاد (قبة الصخرة…) ترفض الخبر.
- اسم «المومني» وحده يُصنَّف قسم «أخبار المومني».
- منع التكرار: الرابط المطبَّع، بصمة العنوان، وتشابه العناوين (Jaccard ≥ 0.8). الخبر نفسه من مصدر آخر يُسجَّل مرجعاً في `news_refs` لا نسخة جديدة.
- سجل كل تشغيل في `fetch_runs`، وحالة كل مصدر في `sources.last_status/last_error`.

## الحقوق والحدود
- نخزّن العنوان ومقتطفاً قصيراً من الخلاصة والرابط الأصلي واسم المصدر والتاريخ فقط. لا نسخ للمقال، لا صور من المصادر، لا تجاوز لتسجيل دخول أو CAPTCHA.
- RSS فقط؛ المصادر من نوع html تُعلَّم غير مدعومة ولا تُكشط.
- روابط https فقط، حد 2MB للاستجابة، رفض DOCTYPE/ENTITY.
- راجع شروط استخدام كل موقع قبل إضافته.
- خلاصات مرشّحة (غير متحقق منها، من قائمة طرف ثالث): jo24.net/feed/، alghad.com/feed، assabeel.net/feeds، jfranews.com.jo/feed/، watananews.com/?feed=rss2. تحقق من كل رابط يدوياً.
- جدولة GitHub قد تتأخر وتتوقف بعد 60 يوماً دون نشاط في المستودع.

## الاختبار
`cd fetcher && python3 -m unittest discover -s tests -t .` (28 اختباراً، تعمل دون شبكة).
لم يُختبر بعد على Supabase الحقيقي ولا على خلاصات حقيقية (الشبكة محجوبة هنا).
