# قائمة اختبار على جهاز حقيقي

لا أستطيع بناء أو تشغيل التطبيق في بيئتي (لا يوجد Android SDK)، فكل واجهات Kotlin لم تُرَ على شاشة.
شغّل هذه القائمة على هاتف حقيقي بعد تثبيت أحدث APK، وأرسل لي لقطة شاشة أو نص الخطأ لأي بند يفشل.

## الأخبار والصفحة الرئيسية
- [ ] تظهر أخبار حقيقية (من الجالب) وليست تجريبية.
- [ ] تبويبات المناطق تصفّي. البحث يعمل.
- [ ] أزرار الترتيب (الأحدث / الأكثر مشاهدة / إعجاباً / تعليقاً / منشورات جديدة) تغيّر الترتيب، والتمرير يحمّل المزيد بنفس الترتيب.
- [ ] فتح خبر ثم الرجوع: عدّاد «الأكثر مشاهدة» يزيد (حسب أدمن: المؤشرات ← الأكثر قراءة).
- [ ] القائمة الجانبية تفتح من اليمين وكل عناصرها تعمل.

## النشر
- [ ] «بم تفكر؟» يفتح، نشر نص ثم نص + صورة. تظهر الرسالة «بانتظار الاعتماد».
- [ ] المنشور لا يظهر للعامة قبل الاعتماد، ويظهر بعده. «منشوراتي» تعرض حالته.
- [ ] خبر فيه كلمة محظورة يظهر عند الأدمن أولاً مع ⚠.

## الإدارة
- [ ] المؤشرات: الأرقام + الأكثر قراءة + المصادر + منشورات المستخدمين.
- [ ] الأخبار ← «كلمات محظورة»: إضافة وحذف. تعليق فيه الكلمة يُخفى تلقائياً.
- [ ] تمييز خبر في «أبرز الأخبار» يظهر في الشريط.

## الإشعارات والتحديث
- [ ] إشعار الدفع يصل (بعد نشر send-push حسب docs/PUSH_FCM.md).
- [ ] الإعدادات ← البحث عن تحديثات ← تنزيل ← تثبيت (بعد تشغيل Publish APK release).
- [ ] الإعلان (Start.io) يظهر ولا يعطّل الشاشة.
